# Como contribuir com o VôLanchar

Agradecemos seu interesse em contribuir com o VôLanchar! O projeto está aberto a sugestões, correções de problemas e melhorias que contribuam para a experiência de compradores e vendedores no ambiente universitário.

## 1. Contribuindo com o projeto

1. Faça um *fork* do repositório.
2. Crie uma branch para desenvolver sua alteração.
3. Realize as modificações seguindo a estrutura e os padrões do projeto.
4. Verifique o funcionamento das funcionalidades afetadas.
5. Abra um *Pull Request* descrevendo as alterações realizadas.

## 2. Tecnologias utilizadas

O projeto utiliza:

- **Python e Kivy:** desenvolvimento do aplicativo Android.
- **Flask:** implementação da API.
- **MySQL/TiDB Cloud:** armazenamento dos dados.
- **Buildozer:** compilação do aplicativo Android.

As contribuições devem respeitar a arquitetura do projeto e evitar a inclusão de dependências desnecessárias.

## 3. Organização do repositório

- `app/` — Código-fonte do aplicativo Android.
- `backend/` — Código-fonte da API Flask.
- `docs/` — Documentação do projeto.

## 4. Testes e qualidade

Antes de enviar uma contribuição:

- Verifique se o código Python apresenta erros de sintaxe.
- Teste as funcionalidades que foram modificadas.
- Confira se a comunicação entre aplicativo e API continua funcionando.
- Mantenha os comentários e a documentação atualizados.
- Descreva os testes realizados no *Pull Request*.

## 5. Segurança e privacidade

Não publique senhas, tokens, chaves privadas, arquivos `.env`, bancos de dados com informações pessoais ou outros dados sensíveis.

Utilize variáveis de ambiente para configurações privadas e dados fictícios durante os testes.

## 6. Comunicação

Sugestões, dúvidas e problemas podem ser registrados na seção **Issues** do GitHub. Para alterações no código, utilize **Pull Requests**.

Agradecemos por contribuir com o desenvolvimento do VôLanchar!
