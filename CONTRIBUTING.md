# Como contribuir

1. Faça um fork do projeto e crie uma branch para sua alteração.
2. Mantenha a compatibilidade com Python 3.10+ e prefira a biblioteca padrão.
3. Rode `python -m unittest -v` antes de enviar suas mudanças.
4. Abra um Pull Request com uma descrição clara do que mudou.

Não envie banco de dados local, senhas, tokens, credenciais ou dados pessoais reais.
